# caw

Progress repository for the upsk.to AI instructor program.

## Structure

- `upsk/proofs/` — proof files (module-by-module summaries, evidence, artifacts) used to advance each upsk step.
- `upsk/workspace-progress/` — repro scripts, probes, reports, and evidence collected in the upsk system-design workspace.

## Skills covered

- System Design Fundamentals (modules 1-10)
- Debugging & Incident Response (modules 1-6+)

Each module is committed after completion.
