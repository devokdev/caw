# Module 10: CI/CD & Deployment - Evidence

## Deployment artifacts

### Dockerfile
- `python:3.12-slim` base
- Installs libpq (psycopg2 compile deps)
- Installs pinned requirements
- Runtime CMD runs migrations then starts uvicorn on `${PORT:-8000}`
- `.dockerignore` excludes venv, caches, logs, secrets, progress

### railway.json
- Dockerfile builder
- Health check on `/health`
- ON_FAILURE restart with 10 max retries
- Single replica

### GitHub Actions (`.github/workflows/ci.yml`)
- **test job**: Postgres 16 + Redis 7 as services, runs migrations, runs full pytest
  suite, verifies the search query EXPLAIN plan uses the trigram index (fails build if
  the search hot path degrades to a Seq Scan)
- **docker-build job**: builds the image (runs after tests pass)

### docker-compose (infra/docker-compose.yml)
- postgres + redis + api with health-gated startup ordering
